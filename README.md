# AirLoop Hair Dryer

An interactive hair dryer state model built with HTML, CSS, and JavaScript.

[View the live demo](https://airloop-dryer-model-20261109.fengtinglu1020.chatgpt.site/)

## Features

- Independent Low, Medium, and High airflow settings
- Cool, Low, Medium, and High heat settings
- Press-and-hold Cool Shot behavior
- Gradual heating and cooling
- Residual heat warning after shutdown
- Overheat protection with active fan cooling while plugged in
- Passive cooling while unplugged
- Responsive desktop and mobile layout

## Files

- `index.html` — interface structure
- `styles.css` — responsive visual design
- `script.js` — device state and interaction logic

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.
